# Git rebase vs merge — reel script (example)

Topic: Git rebase vs merge
Promise: know when to rebase and when to merge
Length: ~15 s (a short test script) · 9:16 1080×1920 · 30fps
VO language: en. On-screen text: en.
Theme: commit dots on branch lines that tangle and then straighten

---

## S1 · HOOK · [hook]
VO: [sighing] Your git history is a mess... [pause] and merge is not the only way out.
- @mess: tangled branch lines fill the screen, commit dots blinking
- @merge: chip "MERGE" slams in, then gets a question mark
Filler: branch lines keep crossing

## S2 · REBASE · [rebase]
VO: [excited] Rebase replays your commits on top of main. One straight line, no merge bubbles.
- @replays: commits lift off one by one and land on main
- @straight: the line snaps straight, chip "LINEAR HISTORY"
Filler: commit dots pulse as they land

## S3 · CTA · [cta]
VO: Rebase local work, merge shared branches. Follow for more.
- @Rebase: two chips "REBASE: LOCAL" and "MERGE: SHARED"
- @Follow: FOLLOW flies up into the final title
