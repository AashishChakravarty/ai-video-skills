# AI Video Skills (shortcut)

`/ai-video-skills` is the reel workflow: run the `ai-video-skills:reel` skill with the Skill tool, passing these
arguments unchanged. This folder is linked into the skills folder only for this shortcut (README "Install"); the
plugin itself provides `/ai-video-skills:reel` and `/ai-video-skills:carousel`.
